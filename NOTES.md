# Notes

Preferences and working notes for this teaching workspace, not covered by the other files.

- **Lessons are Jupyter notebooks (`.ipynb`), not HTML** — a deliberate deviation from this skill's default. Delivery is the Deno kernel (`deno jupyter --install`), opened in VS Code Insiders (`code-insiders <path>` — not `insiders`, that's not the actual CLI name). Rationale: the mission wants markdown narrative interleaved with runnable code and persisted output, which `.ipynb` does natively; Zed's REPL doesn't fit (see below).
- **Zed is out.** Zed's REPL runs `.ts` files with `// %%` cell markers, not `.ipynb` files — doesn't match the notebook format this project needs. Dropped from the delivery story entirely, not just deprioritized.
- **`learning-records/` is gitignored.** Ricky wants his in-progress mistakes/corrections kept local and private, not published in the clone-and-follow-along repo.
- **Repo is triple-purpose**: Ricky's own learning workspace, a public clone-and-follow-along resource, and the source material for a conference talk. Every lesson needs to stand alone for a stranger with no live help — not just make sense to Ricky.
- **Commit convention: Conventional Commits**, one logical unit of work per commit (see `AGENTS.md`).
- **Marketing vs. technical docs is a real finding, not just a caveat.** `research/typesafe-ai.md` found the vendor's "0% hallucination" marketing claim contradicted by TypeSafe's own technical docs, which only guarantee output *shape*, not answer *correctness*. Good talk material — "read primary sources, don't trust the pitch" — not a footnote to bury.
- **Talk date not yet set** — ask when known, it affects pacing/scope.
- **Check-for-understanding format: predict-then-run.** The stock skill's quiz convention (equal-length text answers, in-browser) has no notebook equivalent. Settled on: after a runnable cell, ask the reader to change one input and predict the answer before re-running. Used in lessons 1 and 2 — this is now the standard, not a per-lesson improvisation.
- **`reference/` deferred.** Not enough surface area yet to justify a cheat-sheet doc (e.g. a "Primitives" reference) — start one once at least the three primitives are covered.
- **Lessons live in `lessons/core-concepts/` and `lessons/patterns/`**, not a flat `lessons/`, mirroring `GLOSSARY.md`'s own Core Concepts / Patterns split rather than inventing a third taxonomy. Lesson numbers stay global across both folders (they mean "position in the overall sequence"), so a folder can have gaps — `core-concepts/` holds 0001, 0002, and 0006, skipping over the patterns lessons in between. Every notebook imports the shared client as `../../assets/typesafe-client.ts` (one directory deeper than a flat layout would need) — re-typecheck with `deno check` after moving or adding a lesson, don't just eyeball the path.
- **Reference docs will be Markdown, not HTML** when they start — a deliberate deviation from the stock skill's default, same reasoning family as lessons going `.ipynb`. Plain `.md` views fine in any Markdown viewer as-is, and stays convertible to any other format later without having committed to one up front.
- **Primary sources are embedded inline, not just linked.** Each lesson gets a collapsed `<details><summary>` block (right after the intro cell) containing the actual text of the primary doc page it's built from — no separate link-out, and no sentence in the lesson narrating that it's there ("embedded below, expand it...") — the block speaks for itself. Convert relative doc links to absolute `https://docs.typesafe.ai/...` **without the `.md` suffix** (that suffix is Mintlify's raw-markdown-for-agents convention, per the installed `typesafe:typesafe-ai` skill — drop it for reader-facing links so clicking through opens the rendered page, not raw text), and convert Mintlify JSX (`<Note>...</Note>`) to plain markdown blockquotes before embedding — raw MDX doesn't render in Jupyter/GitHub. The lesson's own prose stays the compressed, talk-ready version; don't quote the same sentence verbatim in both places, and don't reference the collapsed block either — just say the thing.
